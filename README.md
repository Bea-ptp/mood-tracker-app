📱 Mood Tracker App
A simple and intuitive mobile application built with React Native and Expo.
The app allows users to:

Select their mood using emoji buttons

Take a photo using the device camera

Save mood entries with date + photo

View a history of all saved moods

Store data locally using AsyncStorage

🚀 Features
✔ Mood Selection
Choose from multiple emojis to record how you feel.

✔ Camera Integration
Take a photo to attach to your mood entry.

✔ Local Storage
All entries are saved using AsyncStorage.

✔ History Screen
View all past moods with:

Emoji

Date

Optional photo thumbnail

✔ Modern UI
Styled with a custom design system (colors, spacing, typography).
🛠 Technologies Used
React Native

Expo

AsyncStorage

expo-image-picker

React Navigation
